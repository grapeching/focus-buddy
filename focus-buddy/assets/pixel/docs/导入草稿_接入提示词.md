## 三、按你的技术栈替换这段（追加到主提示词末尾）

| 技术栈 | 追加指令 |
|---|---|
| **Unity** | 所有贴图导入设置 `Filter Mode = Point (no filter)`、`Compression = None`、`Sprite (2D and UI)`；用 `SpriteRenderer.sortingOrder` 分层；昼夜用两张 `Image` 的 `CanvasGroup.alpha` 做淡入淡出；拖拽实现 `IDragHandler / IBeginDragHandler / IEndDragHandler`。 |
| **Godot** | 所有 `Sprite2D` 设置 `texture_filter = TEXTURE_FILTER_NEAREST`；用 `CanvasLayer` 或 `z_index` 分层；昼夜用 `Tween` 改 `modulate.a`；拖拽用 `_input` + `Area2D` 热区。 |
| **Web (Canvas / DOM)** | CSS 加 `image-rendering: pixelated;`，Canvas 设 `ctx.imageSmoothingEnabled = false`；背景用两层 `<img>` 叠放改 `opacity` 做 0.5s transition；拖拽用 Pointer Events。 |
| **Python (pygame)** | 用 `pygame.transform.scale()`（不要用 `smoothscale`）；`convert_alpha()` 加载；背景淡入淡出用 `set_alpha()` 逐帧改；拖拽监听 `MOUSEBUTTONDOWN/MOTION/UP`。 |

> 不确定技术栈就把这句加进去：「请先读项目根目录的依赖文件（package.json / *.csproj / project.godot / requirements.txt 等）判断技术栈，再按对应平台的最近邻渲染方式实现，不要猜。」

## 五、三个容易踩的坑

1. **别让 AI 重新生成图片或「优化配色」**。皮毛是程序化统一过的，任何重新生成/调色都会破坏一致性。主提示词里已加禁止条款。
2. **别用平滑缩放**。像素风一旦被双线性过滤就糊成一片，这是接入后最常见的视觉事故。
3. **背景必须同坐标叠放**。昼夜两版机位完全一致，如果分别做成两个场景节点并各自居中，切换时会错位。

如果你告诉我草稿的技术栈（Unity / Godot / Web / Python / 其他）和「玩手机检测」现在的实现方式，我可以把这份提示词改成带具体文件名和函数名的精确版。
