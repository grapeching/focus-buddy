# 专注伙伴 Focus Buddy

一个纯前端的像素小屋学习监督工具：一只猫头鹰陪你学习，学习时盯着你有没有玩手机，休息时它会自己散步、睡觉、吃饭、翻书。

## 快速开始

### Windows 用户（推荐）

直接下载本仓库的两个 `.exe`，**双击即可运行**，无需安装 Python 或敲任何命令：

| 文件 | 用途 |
| --- | --- |
| `专注伙伴.exe` | 完整版：小屋 / 计划 / 学习节奏 / 摄像头监督，含云扬、云夏、云希三套离线配音 |
| `休息测试版.exe` | 休息沙盒：打开就是休息态，带倒计时和时长切换，不接摄像头、不用授权，适合先看效果 |

- 首次启动稍等几秒（exe 自解压 + 模型加载），会弹出一个无地址栏的应用窗口。
- 允许摄像头权限即可使用监督功能。
- 若 Windows Defender 拦截（PyInstaller 打包偶尔被误报），选「更多信息 → 仍要运行」。
- 关掉应用窗口后后台可能残留服务，任务管理器结束同名进程即可完全退出。

### 开发者 / 源码运行

源码在 `focus-buddy/`，是无构建步骤的纯前端项目（HTML / CSS / ES Module）。必须通过 HTTP 访问，不能双击 `index.html`（ES module 在 `file://` 下会被浏览器拦截）：

```bash
cd focus-buddy
python serve.py 8848
# 浏览器打开 http://127.0.0.1:8848/index.html
```

> 别用 `python -m http.server`：它把 `.mjs` 当 `text/plain` 发，ONNX Runtime 的加载器会被浏览器拒绝执行。`serve.py` 已加好正确的 MIME 映射。
>
> Windows 下也可双击 `start.bat`（正式版）或 `start-rest-test.bat`（休息测试版），会自动起服务并打开应用窗口。

## 功能

- **像素小屋**：猫头鹰陪你学习，四种状态（学习 / 警告 / 表扬 / 休息）自动切换。
- **摄像头监督**：MediaPipe 人脸 + COCO-SSD + YOLO11n 本地识别，判断「手持手机 / 桌面平放手机 / 无」，多帧投票降低误报；低头不作为独立判据。所有识别在本机完成，不上传、不保存。
- **四档提醒**：从温和到严厉的文案，所有字幕统一自动配音。
- **三套离线配音**：云扬（沉稳男声，默认）、云夏（童声）、云希（阳光男声），固定台词走本地 MP3、播放不联网，监督页与设置页两处音色选择实时同步。
- **休息态自主行动**：散步、睡觉、吃饭、翻书；休息时可自由拖动猫头鹰，学习时拖走会警告并飞回书桌。

详细说明见 [`focus-buddy/README.md`](focus-buddy/README.md)。

## 环境音说明

原始环境音素材取自商业游戏《呼嚕角落》Demo，版权归 Toe Beans Studio。**本公开仓库中 `focus-buddy/assets/ambient/` 的 4 个 wav 及两个 exe 内的对应资源均已替换为同参数静音占位文件**（不含任何第三方音频）。因此公开版运行时无环境音；如需声音，请自行替换为有合法授权的音频。
